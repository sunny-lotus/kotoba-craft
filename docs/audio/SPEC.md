# ことばクラフト 音の仕様・制作記録

更新：2026-11-02 / 第6版・ユーザー採用 / BGM「ことばのアトリエ」

## 要望と方針

「ことばクラフトにも音をつけたい」という要望から制作。BGMの方向は、ユーザーが選んだ「絵本のアトリエ：静かなピアノと木の響き」。文章を読んだり言葉を探したりする時間に、ゆっくりした音楽を添える。

さんすうの森で採用した、**要望 → 音の設計 → 試作 → 試聴 → 改訂記録 → 実装・確認**の進め方を引き継ぐ。第2〜6版は曲だけを試聴し、ユーザーの「いったんこれで行こう」を受けて第6版を採用した。今後の感想も改訂記録に残す。

## BGMの設計

| 項目 | 内容と意図 |
| --- | --- |
| 曲名 | ことばのアトリエ |
| 拍子・テンポ | 4/4拍子、四分音符＝96。軽やかな古典派風の流れ |
| 長さ | 16小節・40秒のループ |
| 調性 | ヘ長調。明るい主和音・属和音・下属和音を中心にする |
| 主な音色 | 弱く弾いたアップライトピアノの録音素材 |
| 背景の弦 | ヴァイオリンとチェロの持続音を小さく添える。マリンバは使わない |
| 旋律と伴奏 | 旋律は隣り合う音を中心にし、小さいアルベルティ・バスで支える |
| 強弱 | 小節ごとの目標音量を滑らかにつなぎ、4小節の流れでふくらませる |
| 空間 | 狭いステレオ配置と、短く小さな反射音 |
| ドラム・文字入力音 | 付けない。考える時間やタイピングを邪魔しにくくする |

4小節ごとの問いと答えを組み合わせる。4小節目は属和音、8小節目は主和音に着地。後半で少し高い音域へ展開し、16小節目で主和音へ戻る。余韻は前の周回からつながるように書き出す。

## 効果音

さんすうの森でも使用したKenneyの素材を、ことばクラフトの操作へ対応付ける。

| 操作 | 音 | 条件 |
| --- | --- | --- |
| 場面・気持ち・文の部品を開く | 短い決定音 | 画面や選択先が変わった時 |
| カード選択・気持ちの強さの変更 | 軽い木の音 | 文に選択が反映された時 |
| 戻る・選び直す・カードを外す | 紙をめくる音 | 戻る操作が成立した時 |
| 文をためる | 短い完了音 | 保存が成功した時 |
| コピー | 小さいクリック | 「コピーしたよ」と確認できた時 |
| 空欄・保存やコピーの失敗 | 控えめな問いかけ音 | 成功の音と区別する |

「クラフト・ノート・会話」で共通の操作に結び付け、表示処理から音を鳴らさない。戻る確認をキャンセルした時、文字を入力している時、同じ文を再表示した時には、操作の音を追加しない。

## 再生と保存

- BGMと効果音は初回OFF。それぞれON/OFFと音量を変更でき、次回にも保存する。
- 初期音量はBGM 18%、効果音32%。音の設定は `kotoba-craft-sound-v1` に保存し、文の保存データ `kotoba-craft-v1` と分ける。
- 必要になった時だけ読み込み、BGMは音源のデコードを待ってから再生する。途中から電子音が混ざる開始にしない。
- タブを離れた時は停止し、戻った時はON/OFF設定に従う。BGMは先頭から再開する。
- 音が取得できなかった場合は予備の軽い音を使い、作文の操作を続けられるようにする。

## 確認の記録

- 40.000秒、ステレオ22.05 kHz、MP3 641,610 bytes。圧縮後ピーク約0.221、RMS約0.0398、ループ端のサンプル差約0.000439。クリッピングと大きな継ぎ目を数値で確認。
- 初回の無音、必要な時だけの読み込み、キャッシュ、3表示でのカード操作、保存・コピー成功時の音、再表示での重複防止を自動確認。
- 第6版の切り替え後もBGMと効果音の独立したOFF、タブ切り替え、読込失敗時も作文を続けられることを確認。
- 「心地よい」「言葉を考えやすい」といった主観的な評価は、今後も試聴して調整する。
